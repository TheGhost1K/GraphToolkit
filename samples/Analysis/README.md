# Analysis — анализ социальной сети

Пример показывает полный пайплайн анализа графа через библиотеку
GraphToolkit:

1. **Загрузка** графа из JSON-файла.
2. **Общая статистика** — размеры, средняя степень, диапазон весов.
3. **PageRank** — важность пользователей по структуре связей.
4. **Центральности** — Degree, Closeness, Betweenness.
5. **Louvain** — обнаружение сообществ с максимизацией модулярности.
6. **Лидеры** каждого сообщества по PageRank.
7. **Комбинированный рейтинг** — 50% PageRank + 30% Betweenness + 20% Closeness.
8. **Мосты** — кто связывает разные сообщества.
9. **Визуализация** в Mermaid с раскраской по сообществам.
10. **Экспорт** результатов в JSON.

## Запуск

```bash
cd samples/Analysis
dotnet run
```

## Как адаптировать под свои данные

1. Замените `data/social-network.json` своим файлом
   (или используйте GraphML / CSV — см. `GraphIO`).
2. Измените путь в `Program.cs`:

   ```csharp
   var dataPath = Path.Combine(
       AppContext.BaseDirectory, "data", "my-data.json");
   ```

3. Настройте веса комбинированного рейтинга под свою задачу:

   ```csharp
   var combined = graph.Vertices.ToDictionary(
       v => v,
       v => 0.6 * pageRank[v] + 0.4 * betweenness[v]);
   ```
