# Matching — паросочетания и назначения

Пример демонстрирует три алгоритма паросочетаний из библиотеки
GraphToolkit:

1. **Куна** — максимальное паросочетание в **двудольном** графе
   (например, студенты ↔ курсы).
2. **Blossom** (Эдмондса) — максимальное паросочетание в **общем**
   графе, включая графы с нечётными циклами.
3. **Венгерский** — **оптимальное назначение** в двудольном взвешенном
   графе (например, распределение задач с минимизацией времени).

## Когда какой алгоритм использовать

| Алгоритм | Тип графа | Что решает |
|---|---|---|
| Куна | Двудольный (невзвешенный) | Максимум пар |
| Blossom | Общий (невзвешенный) | Максимум пар |
| Венгерский | Двудольный (взвешенный) | Минимум/максимум стоимости |

**Важно:** Куна и Blossom максимизируют **число пар**, Венгерский —
**суммарный вес**. Это разные задачи.

## Что демонстрируется

### Куна — двудольный граф

```csharp
var students = new[] { "Алиса", "Борис", "Вика" };
var preferences = new Dictionary<string, string[]>
{
    ["Алиса"] = new[] { "Математика", "Физика" },
    ["Борис"] = new[] { "Математика" },
    ["Вика"]  = new[] { "Физика", "Химия" }
};

var matching = Kuhn.Compute(students, s => preferences[s]);
foreach (var (student, course) in matching)
    Console.WriteLine($"{student} → {course}");
```

### Blossom — общий граф

```csharp
var g = new GraphBuilder<string>(isDirected: false)
    .AddEdge("A", "B")
    .AddEdge("B", "C")
    .AddEdge("C", "A")     // нечётный цикл
    .AddEdge("C", "D")
    .Build();

var matching = Blossom.Compute(g);
bool perfect = Blossom.HasPerfectMatching(g);
```

### Венгерский — оптимальное назначение

```csharp
var costMatrix = new double[,]
{
    { 9, 2, 7, 8 },
    { 6, 4, 3, 7 },
    { 5, 8, 1, 8 }
};

// Минимизация
var min = HungarianAlgorithm.Solve(costMatrix);

// Максимизация (например, прибыль)
var max = HungarianAlgorithm.SolveMaximization(profitMatrix);

// Прямоугольная матрица
var rect = HungarianAlgorithm.SolveRectangular(rectangularMatrix);
```

## Применения

- **Куна**: распределение студентов, задачи о назначениях,
  сопоставление доноров и реципиентов
- **Blossom**: разбиение на пары, обработка изображений,
  общие задачи паросочетания
- **Венгерский**: транспортные задачи, распределение ресурсов,
  планирование производства, медицинские назначения
