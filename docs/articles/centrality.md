# Центральности и PageRank

**Центральность** — мера «важности» вершины в графе. Разные метрики
определяют важность по-разному: через степень, расстояния, количество
кратчайших путей или глобальную структуру. Библиотека реализует
шесть классических метрик.

## Быстрый обзор

| Метрика | Что измеряет | Сложность |
|---|---|---|
| Degree | Нормированная степень вершины | O(V) |
| Closeness | Обратная сумма расстояний до всех вершин | O(V · (V + E) log V) |
| Betweenness | Доля кратчайших путей через вершину | O(V · (V + E) log V) |
| Eigenvector | Центральность по собственному вектору матрицы смежности | O(iter · (V + E)) |
| Katz | Взвешенная сумма всех путей | O(iter · (V + E)) |
| PageRank | Стационарное распределение случайного блуждания | O(iter · (V + E)) |

Все методы возвращают `Dictionary<T, double>` — словарь «вершина → значение».

---

## PageRank

Классический алгоритм Google для ранжирования веб-страниц. Работает
для любого ориентированного графа: чем больше на вершину ссылаются
«важные» вершины, тем выше её ранг.

### Пример

```csharp
using GraphToolkit.Centrality;
using GraphToolkit.Utils;

var graph = new GraphBuilder<string>(isDirected: true)
    .AddEdge("Главная", "Новости")
    .AddEdge("Главная", "Каталог")
    .AddEdge("Новости", "Каталог")
    .AddEdge("Каталог", "Товар 1")
    .AddEdge("Каталог", "Товар 2")
    .AddEdge("Товар 1", "Главная")
    .AddEdge("Товар 2", "Каталог")
    .Build();

var ranks = PageRank.Compute(graph, damping: 0.85, iterations: 100);

foreach (var (page, rank) in ranks.OrderByDescending(kv => kv.Value))
    Console.WriteLine($"{page,-12} {rank:F4}");
```

Примерный вывод:

```
Каталог       0.3215
Главная       0.2740
Новости       0.1825
Товар 1       0.1110
Товар 2       0.1110
```

### Формула

```
PR(v) = (1 - d) / V + d · Σ_{u → v} PR(u) / outdeg(u)
```

где `d` — damping factor (обычно 0.85), `V` — число вершин.
Сумма всех `PR(v)` ≈ 1.

### Параметры

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `damping` | 0.85 | Вероятность продолжить блуждание (а не «телепортироваться») |
| `iterations` | 100 | Максимум итераций |
| `tolerance` | 1e-6 | Порог сходимости |

### Применения

- Ранжирование веб-страниц
- Анализ цитирований в научных работах
- Рекомендательные системы
- Ранжирование пользователей в соцсетях

### Параллельный PageRank

Для больших графов используйте параллельную версию:

```csharp
using GraphToolkit.Parallel;

var ranks = ParallelPageRank.Compute(graph, damping: 0.85, iterations: 100);
```

**Ускорение:** 4–8× на многоядерных машинах.

Результаты **идентичны** последовательной версии (проверено
юнит-тестами с точностью 1e-6).

См. подробнее в статье [«Параллельные алгоритмы»](parallel-algorithms.md).

## Degree centrality

Самая простая метрика: степень вершины, нормированная на `V - 1`.

```csharp
var centrality = Centralities.Degree(graph);

// centrality[v] ∈ [0, 1]
// 1.0 — вершина соединена со всеми остальными
```

**Когда использовать:** быстрое приближение важности, «хабы» в сети.

---

## Closeness centrality

Обратная сумма кратчайших расстояний до всех остальных вершин:

```
C(v) = (n - 1) / Σ_{u ≠ v} d(v, u)
```

Чем ближе вершина ко всем остальным, тем выше значение.

```csharp
var centrality = Centralities.Closeness(graph);
```

**Сложность:** O(V · (V + E) log V) — V запусков Дейкстры.

**Применения:**
- Оптимальное размещение сервисов (больниц, складов)
- Выявление «мостов» между кластерами
- Социальные сети: кто быстрее всего распространит информацию

---

## Betweenness centrality

Доля кратчайших путей между всеми парами вершин, проходящих через данную
вершину. **Алгоритм Брандеса.**

```csharp
var centrality = Centralities.Betweenness(graph);
```

**Применения:**
- Поиск «узких мест» в транспортных сетях
- Выявление ключевых фигур в соцсетях (не по степени, а по «связности»)
- Анализ белковых взаимодействий

**Пример:** в графе «A — B — C — D» вершина B имеет высокую
betweenness, потому что все кратчайшие пути между A и C, A и D, B и D
проходят через неё.

---

## Eigenvector centrality

Центральность по **собственному вектору** матрицы смежности. Идея:
вершина важна, если она соединена с другими важными вершинами.

```csharp
var centrality = Centralities.Eigenvector(graph);
```

Реализовано методом степенных итераций: `x_{k+1} = A · x_k / ||A · x_k||`.

**Применения:**
- Определение «влиятельных» узлов в сетях
- Анализ цитирований
- Поисковая выдача (предшественник PageRank)

**Сравнение с PageRank:** Eigenvector не учитывает «телепортацию» —
на графах с висячими вершинами может не сходиться. PageRank
устойчивее.

---

## Katz centrality

Взвешенная сумма всех путей между вершинами с экспоненциальным
затуханием по длине:

```
x_{k+1} = α · A · x_k + β · 1
```

```csharp
var centrality = Centralities.Katz(graph, alpha: 0.1, beta: 1.0);
```

**Параметры:**
- `alpha` — коэффициент затухания, обычно `< 1 / λ_max`
- `beta` — «базовая» центральность для вершин без входящих рёбер

**Применения:**
- Когда у графа есть изолированные вершины (в отличие от Eigenvector)
- Анализ соцсетей с «молчунами»
