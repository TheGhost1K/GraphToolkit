# Паросочетания

**Паросочетание** — множество рёбер без общих вершин.

## Куна — двудольный граф

**Сложность:** O(V · E).
**Применимо к:** двудольный граф.

```csharp
using GraphToolkit.Matching;

var left = new[] { "A", "B", "C" };
var right = new[] { "X", "Y", "Z" };

var neighbors = new Dictionary<string, string[]>
{
    ["A"] = new[] { "X", "Y" },
    ["B"] = new[] { "X" },
    ["C"] = new[] { "Y", "Z" }
};

var matching = Kuhn.Compute(left, u => neighbors[u]);

foreach (var (u, v) in matching)
    Console.WriteLine($"{u} ↔ {v}");
// A ↔ Y
// B ↔ X
// C ↔ Z
```

### Когда использовать

- Задача о назначениях
- Сопоставление студентов и курсов
- Рекомендательные системы

---

## Blossom (Эдмондс) — общий граф

**Сложность:** O(V³).
**Применимо к:** произвольный неориентированный граф.

```csharp
using GraphToolkit.Matching;
using GraphToolkit.Utils;

var graph = new GraphBuilder<int>(isDirected: false)
    .AddEdge(0, 1)
    .AddEdge(1, 2)
    .AddEdge(2, 0)  // нечётный цикл (граф не двудольный!)
    .AddEdge(2, 3)
    .Build();

var matching = Blossom.Compute(graph);

foreach (var (u, v) in matching)
    Console.WriteLine($"{u} ↔ {v}");
```

### Проверка совершенного паросочетания

```csharp
if (Blossom.HasPerfectMatching(graph))
    Console.WriteLine("Существует паросочетание, покрывающее все вершины");
```

## Сравнение

| | Куна | Blossom |
|---|---|---|
| Тип графа | Двудольный | Общий |
| Сложность | O(V·E) | O(V³) |
| Простота | Высокая | Низкая |

## Венгерский алгоритм (задача о назначениях)

Задача: дана матрица стоимостей `cost[i, j]`. Нужно найти перестановку
`σ`, минимизирующую `Σ cost[i, σ(i)]`.

**Классический пример:** n работников, n задач. `cost[i, j]` — стоимость
выполнения задачи j работником i. Найти оптимальное распределение.

### Минимизация

```csharp
using GraphToolkit.Matching;

var cost = new double[,]
{
    { 10, 5, 13 },
    { 3, 7, 9 },
    { 6, 8, 4 }
};

var result = HungarianAlgorithm.Solve(cost);

Console.WriteLine($"Минимальная стоимость: {result.TotalCost}");
foreach (var (row, col) in result.Assignments)
    Console.WriteLine($"  Работник {row} → Задача {col}");
// Минимальная стоимость: 12
//   Работник 0 → Задача 1
//   Работник 1 → Задача 0
//   Работник 2 → Задача 2
```

### Максимизация

Аналогично, но через `SolveMaximization`:

```csharp
var profit = new double[,]
{
    { 10, 5, 13 },
    { 3, 7, 9 },
    { 6, 8, 4 }
};

var best = HungarianAlgorithm.SolveMaximization(profit);
Console.WriteLine($"Максимальная прибыль: {best.TotalCost}");
```

### Прямоугольная матрица

Если работников меньше, чем задач (m < n):

```csharp
var cost = new double[,]
{
    { 5, 2, 8 },   // работник 0
    { 3, 7, 1 }    // работник 1
};

var result = HungarianAlgorithm.SolveRectangular(cost);
// Внутри дополнит до 3×3 фиктивными работниками
```

**Ограничение:** `SolveRectangular` требует `m ≤ n` — работников
не больше, чем задач.

### Сложность

O(n³). Эффективен для задач до нескольких тысяч элементов.

### Применения

- Распределение задач между исполнителями
- Назначение рейсов экипажам
- Сопоставление товаров и складов
- Медицинские назначения (доноры ↔ реципиенты)
- Обнаружение объектов (сопоставление детекций с треками)

### Сравнение с другими алгоритмами

| Алгоритм | Тип графа | Задача |
|---|---|---|
| Куна | Двудольный (невзвешенный) | Максимальное паросочетание |
| Blossom | Общий | Максимальное паросочетание |
| **Венгерский** | Двудольный взвешенный | Оптимальное назначение |

## Итоговая таблица алгоритмов

| Алгоритм | Тип графа | Что решает | Сложность |
|---|---|---|---|
| Куна | Двудольный, невзвешенный | Максимальное паросочетание | O(V · E) |
| Blossom / Эдмондс | Общий, невзвешенный | Максимальное паросочетание | O(V³) |
| **Венгерский** | Двудольный, **взвешенный** | **Оптимальное назначение** | O(V³) |

**Ключевое отличие:** Куна и Blossom максимизируют **число пар**,
Венгерский минимизирует (или максимизирует) **суммарный вес**.
