# Обходы графа (BFS, DFS)

## BFS — поиск в ширину

**Сложность:** O(V + E)
**Пространство:** O(V)
**Структура:** очередь

Находит **кратчайший путь по числу рёбер** в невзвешенном графе.

### Пример

```csharp
using GraphToolkit.Traversal;
using GraphToolkit.Utils;

var graph = new GraphBuilder<string>(isDirected: true)
    .AddEdge("A", "B")
    .AddEdge("A", "C")
    .AddEdge("B", "D")
    .AddEdge("C", "D")
    .AddEdge("D", "E")
    .Build();

var path = Bfs.FindPath(graph, "A", "E");
Console.WriteLine(string.Join(" -> ", path));
// A -> B -> D -> E
```

### Когда использовать

- ✅ Невзвешенный граф
- ✅ Нужен кратчайший по рёбрам путь
- ✅ Поиск по уровням (BFS-слои)
- ❌ Взвешенный граф — используйте [Дейкстру](shortest-paths.md)

## DFS — поиск в глубину

**Сложность:** O(V + E)
**Структура:** стек

Находит **любой** путь; не гарантирует кратчайший.

```csharp
var path = Dfs.FindPath(graph, "A", "E");
Console.WriteLine(string.Join(" -> ", path));
```

> [!NOTE]
> Реализация итеративная, что исключает переполнение стека
> на больших графах.

### Когда использовать

- ✅ Нужен любой путь, а не кратчайший
- ✅ Поиск циклов, топологическая сортировка, SCC
- ✅ Обход "в глубину" для классических задач
- ❌ Нужна оптимальность по рёбрам — используйте BFS

## Сравнительная таблица

| Характеристика | BFS | DFS |
|---|---|---|
| Структура данных | Очередь | Стек |
| Кратчайший путь (рёбра) | ✅ | ❌ |
| Использование памяти | Больше | Меньше |
| Порядок обхода | По уровням | Вглубь |
