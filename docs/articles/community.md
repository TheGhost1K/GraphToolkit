# Обнаружение сообществ

**Сообщество** — подмножество вершин, внутри которого связи плотнее,
чем с остальным графом. Задача поиска сообществ возникает в анализе
социальных сетей, биоинформатике, рекомендательных системах.

Библиотека реализует два алгоритма:

- **Label Propagation** — быстрый, но нестабильный
- **Louvain** — медленнее, но максимизирует модулярность

---

## Label Propagation

Каждая вершина итеративно принимает метку самого «весомого» соседа.
За несколько итераций граф распадается на сообщества.

### Пример

```csharp
using GraphToolkit.Community;
using GraphToolkit.Utils;

var graph = new GraphBuilder<int>(isDirected: false)
    .AddEdge(1, 2).AddEdge(2, 3).AddEdge(3, 1)   // клика 1
    .AddEdge(4, 5).AddEdge(5, 6).AddEdge(6, 4)   // клика 2
    .AddEdge(3, 4)                                // мост
    .Build();

var communities = LabelPropagation.Compute(graph, seed: 42);

foreach (var c in communities)
    Console.WriteLine("{" + string.Join(", ", c) + "}");
// {1, 2, 3}
// {4, 5, 6}
```

### Сложность

**O(iter · E)**. Обычно сходится за 5–10 итераций.

### Параметры

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `maxIterations` | 20 | Максимум итераций |
| `seed` | null | Seed для воспроизводимости (`null` — случайный) |

### Особенности

> [!WARNING]
> **Не детерминирован.** Результат может отличаться между запусками.
> Для воспроизводимости передавайте `seed`.

> [!NOTE]
> **Не гарантирует качество.** На графах с размытыми границами
> может слить несколько «истинных» сообществ в одно.

### Применения

- Быстрый предварительный анализ больших графов
- Полуавтоматическая разметка
- Прототипирование

---

## Louvain

Алгоритм **Лувена** максимизирует **модулярность** — метрику качества
разбиения. Работает в два этапа:

1. **Локальная оптимизация** — каждая вершина пытается перейти в
   сообщество соседа, если это увеличивает модулярность.
2. **Агрегация** — сообщества сжимаются в супервершины,
   процесс повторяется.

### Пример

```csharp
var graph = new GraphBuilder<int>(isDirected: false)
    .AddEdge(1, 2, 1).AddEdge(2, 3, 1).AddEdge(3, 1, 1)
    .AddEdge(1, 4, 1).AddEdge(2, 4, 1).AddEdge(3, 4, 1)   // клика из 4
    .AddEdge(5, 6, 1).AddEdge(6, 7, 1).AddEdge(7, 5, 1)
    .AddEdge(5, 8, 1).AddEdge(6, 8, 1).AddEdge(7, 8, 1)   // клика из 4
    .AddEdge(4, 5, 0.1)                                    // слабый мост
    .Build();

var communities = Louvain.Compute(graph);

foreach (var c in communities)
    Console.WriteLine("{" + string.Join(", ", c) + "}");

double q = Louvain.Modularity(graph, communities);
Console.WriteLine($"Модулярность: {q:F4}");
```

### Модулярность

Метрика качества разбиения:

```
Q = (1 / 2m) · Σ_{ij} (A_ij − k_i · k_j / 2m) · δ(c_i, c_j)
```

- `A_ij` — вес ребра между `i` и `j`
- `k_i` — сумма весов рёбер вершины `i`
- `m` — общая сумма весов
- `δ(c_i, c_j)` = 1, если вершины в одном сообществе

**Диапазон:** от −0.5 до 1. Чем выше — тем лучше.

| Значение Q | Интерпретация |
|---|---|
| > 0.3 | Хорошая структура сообществ |
| 0.2–0.3 | Слабая структура |
| < 0.2 | Практически нет структуры |

### Сложность

**O(V log V · E)** на практике.

### Особенности

> [!NOTE]
> **Детерминирован.** Результат одинаков между запусками.

> [!WARNING]
> **Не гарантирует глобальный оптимум.** Louvain — жадный алгоритм,
> может застрять в локальном максимуме модулярности.

### Применения

- Анализ сообществ в соцсетях
- Разбиение графа на кластеры для визуализации
- Сегментация пользователей
- Биоинформатика (функциональные модули белковых сетей)

## Сравнение алгоритмов

| | Label Propagation | Louvain |
|---|---|---|
| Сложность | O(iter · E) | O(V log V · E) |
| Детерминирован | ❌ | ✅ |
| Качество | Среднее | Высокое |
| Максимизирует модулярность | Нет | Да |
| Подходит для больших графов | ✅ | ✅ |

**Рекомендация:** используйте Louvain по умолчанию, Label Propagation —
для очень больших графов (> 10⁶ вершин), где скорость критичнее качества.

## Взвешенный Label Propagation

Улучшенная версия, учитывающая **веса рёбер** при выборе метки соседа.
Даёт более качественное разбиение на графах с сильно различающимися
весами.

```csharp
using GraphToolkit.Community;

var communities = WeightedLabelPropagation.Compute(graph, seed: 42);
```

**Когда использовать:**

- Веса рёбер сильно различаются (> 10×)
- Есть чёткие «мосты» между группами
- Нужно более устойчивое разбиение
