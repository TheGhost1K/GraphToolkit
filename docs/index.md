# GraphToolkit

> Комплексная библиотека графовых алгоритмов для .NET 10+

## Основные возможности

| Категория | Алгоритм — что решает | Сложность |
|---|---|---|
| **Обходы** | BFS — обход в ширину | O(V + E) |
| | DFS — обход в глубину | O(V + E) |
| | Топологическая сортировка (Кана) | O(V + E) |
| **Кратчайшие пути** | Дейкстра — от одного источника | O((V+E) log V) |
| | Беллман-Форд — с отрицательными весами | O(V · E) |
| | A* — эвристический поиск | Зависит от эвристики |
| | Флойд-Уоршелл — все пары | O(V³) |
| | Критический путь — самый длинный в DAG | O(V + E) |
| **MST** | Краскал — разреженные графы | O(E log E) |
| | Прим — плотные графы | O((V+E) log V) |
| | Борувка — параллелизуемый | O(E log V) |
| **Компоненты** | Связные компоненты | O(V + E) |
| | SCC (Косараю) — сильная связность | O(V + E) |
| | Мосты и точки сочленения (Тарьян) | O(V + E) |
| **Потоки** | Форд-Фалкерсон — классика | O(E · f) |
| | Эдмондс-Карп — BFS-версия | O(V · E²) |
| | Диниц — быстрейший из классических | O(V² · E) |
| **Min-cost flow** | SPFA — с отрицательными стоимостями | O(V · E · F) |
| | Дейкстра с потенциалами (Джонсон) | O(F · E · log V) |
| **Разрезы** | Штёр-Вагнер — глобальный min-cut | O(V³) |
| | Гомори-Ху — все пары min-cut | O(V · MaxFlow) |
| **Паросочетания** | Куна — макс. паросочетание (двудольный) | O(V · E) |
| | Blossom / Эдмондс — макс. паросочетание (общий) | O(V³) |
| | Венгерский — оптимальное назначение | O(V³) |
| **Эйлеровы** | Проверка + Хиерхольцер — эйлеров путь | O(V + E) |
| **Гамильтоновы** | Цикл / путь — перебор с возвратом | O(V!) |
| | TSP — ветви и границы (точный) | O(V² · 2^V) |
| | TSP — ближайший сосед + 2-opt | O(V²) |
| **Раскраска** | Жадная (Уэлш-Пауэлл) | O(V² + E) |
| | Точная (DSATUR) | экспоненциальная |
| | Проверка двудольности | O(V + E) |
| **Деревья** | LCA — наименьший общий предок | O(V log V) + O(log V) |
| | Диаметр дерева | O(V log V) |
| | Центроид дерева | O(V) |
| | Центроидная декомпозиция | O(V log V) + O(log V) |
| | Heavy-Light Decomposition | O(V) + O(log V) |
| | HLD + запросы на путях | O(V) + O(log² V) |
| | Link-Cut Tree | O(log V) амортиз. |
| **Структуры** | Segment Tree — запросы на отрезках | O(log n) |
| | Fenwick Tree — префиксные суммы | O(log n) |
| **Замыкания** | Транзитивное замыкание | O(V³) |
| | Транзитивное сокращение (DAG) | O(V³) |
| **Преобразования** | Клонирование, транспонирование, смена направленности | O(V + E) |
| | Клонирование сетей (`FlowNetwork<T>`, `CostFlowNetwork<T>`) | O(V + E) |
| **Представления** | Матрица смежности `AdjacencyMatrixGraph<T>` | O(V²) памяти |
| **Визуализация** | DOT / Mermaid / матрица / список | — |

## Быстрый старт

```csharp
using GraphToolkit.Utils;
using GraphToolkit.ShortestPaths;

var graph = new GraphBuilder<string>(isDirected: true)
    .AddEdge("A", "B", 4)
    .AddEdge("A", "C", 2)
    .AddEdge("C", "D", 3)
    .Build();

var path = Dijkstra.FindPath(graph, "A", "D");
Console.WriteLine(string.Join(" -> ", path)); // A -> C -> D
```

## Установка

```bash
dotnet add package GraphToolkit
```
