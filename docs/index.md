# GraphToolkit

> Комплексная библиотека графовых алгоритмов для .NET 10+

## Основные возможности

| Категория | Алгоритм — что решает | Сложность |
|---|---|---|
| **Обходы** | BFS — обход в ширину | O(V + E) |
| | DFS — обход в глубину | O(V + E) |
| | Топологическая сортировка (Кана) — порядок вершин в DAG | O(V + E) |
| **Кратчайшие пути** | Дейкстра — кратчайшие пути от одного источника | O((V+E) log V) |
| | Беллман-Форд — кратчайшие пути с отрицательными весами | O(V · E) |
| | A* — эвристический поиск кратчайшего пути | Зависит от эвристики |
| | Флойд-Уоршелл — кратчайшие пути между всеми парами | O(V³) |
| | Критический путь — самый длинный путь в DAG | O(V + E) |
| **MST** | Краскал — минимальное остовное дерево, разреженные графы | O(E log E) |
| | Прим — минимальное остовное дерево, плотные графы | O((V+E) log V) |
| | Борувка — минимальное остовное дерево, параллелизуемый | O(E log V) |
| **Компоненты** | Связные компоненты — компоненты связности | O(V + E) |
| | SCC (Косараю) — сильно связные компоненты | O(V + E) |
| | Мосты и точки сочленения (Тарьян) — уязвимые рёбра и вершины | O(V + E) |
| **Потоки** | Форд-Фалкерсон — максимальный поток, классика | O(E · f) |
| | Эдмондс-Карп — максимальный поток, BFS-версия | O(V · E²) |
| | Диниц — максимальный поток, быстрейший из классических | O(V² · E) |
| | Push-Relabel — максимальный поток, плотные графы | O(V³) / O(V²√E) |
| **Min-cost flow** | SPFA — поток минимальной стоимости с отрицательными стоимостями | O(V · E · F) |
| | Дейкстра с потенциалами (Джонсон) — поток минимальной стоимости | O(F · E · log V) |
| **Разрезы** | Штёр-Вагнер — глобальный минимальный разрез | O(V³) |
| | Гомори-Ху — минимальные разрезы для всех пар вершин | O(V · MaxFlow) |
| **Паросочетания** | Куна — максимальное паросочетание в двудольном графе | O(V · E) |
| | Blossom / Эдмондс — максимальное паросочетание в общем графе | O(V³) |
| | Венгерский — оптимальное назначение (min-cost) | O(V³) |
| **Эйлеровы** | Проверка + Хиерхольцер — эйлеров путь/цикл | O(V + E) |
| **Гамильтоновы** | Цикл / путь — перебор с возвратом | O(V!) |
| | TSP — точное решение задачи коммивояжёра (ветви и границы) | O(V² · 2^V) |
| | TSP — приближённое решение (ближайший сосед + 2-opt) | O(V²) |
| **Раскраска** | Жадная (Уэлш-Пауэлл) — вершинная раскраска | O(V² + E) |
| | Точная (DSATUR) — минимальная вершинная раскраска | экспоненциальная |
| | Проверка двудольности — 2-раскраска графа | O(V + E) |
| **Деревья** | LCA — наименьший общий предок, запросы на дереве | O(V log V) + O(log V) |
| | Диаметр дерева — longest path в дереве | O(V log V) |
| | Центроид дерева — вершина, минимизирующая макс. компоненту | O(V) |
| | Центроидная декомпозиция — разбиение для запросов на путях | O(V log V) + O(log V) |
| | Heavy-Light Decomposition — разбиение дерева для запросов на путях | O(V) + O(log V) |
| | HLD + запросы на путях — запросы на пути в дереве | O(V) + O(log² V) |
| | Link-Cut Tree — динамические деревья с link/cut | O(log V) амортиз. |
| **Структуры** | Segment Tree — запросы min/max/sum на отрезках | O(log n) |
| | Fenwick Tree — префиксные суммы и точечные обновления | O(log n) |
| | CSR-граф — компактное хранение разреженного графа | O(V + E) |
| **Центральности** | PageRank — важность; Degree — по степени; Closeness — близость; Betweenness — посредничество; Eigenvector — по собственному вектору; Katz — с затуханием | O(iter · (V + E)) |
| **Сообщества** | Label Propagation — обнаружение сообществ; Louvain — иерархическое обнаружение сообществ | O(iter · E) — O(V log V · E) |
| | Взвешенный Label Propagation — обнаружение сообществ во взвешенном графе | O(iter · E) |
| **IO** | Чтение/запись графа в форматах GraphML, GEXF, JSON, CSV, DOT | — |
| **Параллельные** | Параллельный BFS — обход в ширину, кратчайшие пути в невзвешенном графе | O((V + E) / cores) |
| | Параллельный PageRank — оценка важности вершин | O(iter · (V + E) / cores) |
| | Параллельный FloydWarshall — все пары кратчайших путей | O(V³ / cores) |
| | Параллельный BellmanFord — кратчайшие пути с отрицательными рёбрами | O(V · E / cores) |
| | Параллельные компоненты — поиск компонент связности | O((V + E) / cores · α) |
| | Параллельный SCC — поиск сильно связных компонент | O((V + E) / cores) |
| | Параллельный Boruvka — минимальное остовное дерево | O(E / cores · log V) |
| | Multi-source BFS — BFS от нескольких источников | O((V + E) / cores) |
| | Delta-stepping Дейкстра — кратчайшие пути во взвешенном графе | O((V + E) / cores · log V) |
| **Замыкания** | Транзитивное замыкание — достижимость всех пар вершин | O(V³) |
| | Транзитивное сокращение — минимальный эквивалентный DAG | O(V³) |
| **Преобразования** | Копирование графа, обращение рёбер, смена ориентированности | O(V + E) |
| | Копирование потоковых сетей с сохранением пропускных способностей и стоимостей | O(V + E) |
| **Представления** | Представление графа в виде матрицы смежности `AdjacencyMatrixGraph<T>` | O(V²) памяти |
| **Визуализация** | Экспорт в DOT / Mermaid, вывод матрицы смежности и списка рёбер | — |
| **CLI** | `graph-toolkit` — утилита командной строки для работы с графом без кода | — |

## Быстрый старт

```csharp
using GraphToolkit.Utils;
using GraphToolkit.ShortestPaths;

var graph = new GraphBuilder<string>(isDirected: true)
    .AddEdge("A", "B", 4)
    .AddEdge("A", "C", 2)
    .AddEdge("C", "D", 3)
    .Build();

var path = Dijkstra.FindPath(graph, "A", "D");
Console.WriteLine(string.Join(" -> ", path)); // A -> C -> D
```

## Установка

```bash
dotnet add package GraphToolkit
```

### CLI

```bash
dotnet tool install -g GraphToolkit.Cli

graph-toolkit info graph.dot
graph-toolkit path graph.dot --from A --to F
graph-toolkit mst graph.dot --algorithm=prim
graph-toolkit visualize graph.dot --format=mermaid
```
